## 📖 Описание выполненной работы

### 1. Сайт (8 страниц + 404)
*   Сайт создан с помощью нейросети (ChatGPT/Gemini), запросы сохранены в `docs/prompts.md`.
*   Вся верстка написана на чистом HTML, CSS и JS (без сборщиков и фреймворков).
*   Сайт опубликован на Vercel и автоматически обновляется при пуше в ветку `main`.
*   Реализована адаптивная верстка (проверено на 375px, 768px, 1280px). Кнопки не менее 44x44px.
*   Присутствуют все обязательные страницы: Главная, Цены (с калькулятором), Инструкторы (с фильтром), Тренажёр ПДД (10 вопросов), Филиалы, Контакты (с формой), Спасибо, Политика конфиденциальности, 404.

### 2. Веб-аналитика (Google Analytics 4)
*   Тег `gtag.js` установлен на всех страницах, включая 404.
*   Настроено 20 событий (6 автосбора и 14 кастомных). Все вызовы находятся в `js/analytics.js`.
*   В GA4 созданы 7 пользовательских параметров (Custom definitions).
*   Настроены 3 ключевых события: `generate_lead`, `contact_click`, `messenger_click`.
*   Все события проверены в режиме DebugView. Скриншоты лежат в `screens/ga4/`.

### 3. UTM-разметка
*   Реестр ссылок ведется в `docs/utm.csv` (сформирован по правилам из ТЗ).
*   Все ссылки проверены переходами. Скриншоты адресной строки и Realtime-отчетов GA4 лежат в `screens/utm/`.
*   Создана короткая ссылка для ВКонтакте (сохраняет все 5 меток).

### 4. Приём заявок
*   Форма на сайте отправляет данные через `fetch` на скрипт Google Apps Script.
*   Скрипт (`apps-script/Code.gs`) проверяет данные на стороне сервера, защищает от дублей (по `request_id`) и записывает строку в таблицу.
*   Все обязательные поля, UTM-метки и статусы (`new`, `contacted`, `contract`, `lost`) работают корректно.
*   При успешной отправке срабатывает событие `generate_lead` и открывается страница `thanks.html` с номером заявки.

### 5. Отчётность и DataLens
*   В GA4 настроены отчеты: Traffic acquisition, User acquisition, Events, Key events.
*   Создана коллекция отчетов «ПРАВЫЙ РЯД» и кастомный отчет по кампании `students_nov_2026`.
*   Настроены два исследования (Explore) с сегментами Instagram и Direct.
*   В Yandex DataLens собран дашборд «ПРАВЫЙ РЯД – students_nov_2026» из трех вкладок (Трафик, Заявки, Кампании) с селекторами периода. Данные подтягиваются из Google Таблицы.
*   Аналитическая записка заполнена в `docs/report.md`. Скриншоты дашборда — в `screens/datalens/`.

### 6. Технические особенности и ограничения
*   **Ограничение Google Рекламы:** В России раздел «Реклама» (пути к ключевым событиям) не заполнялся, так как Google Ads недоступен. Цепочку действий перед заявкой показывает отчет «Обратный путь» из раздела «Исследования».
*   **Причина расхождения цифр:** Расхождение между заявками в таблице и событиями `generate_lead` в GA4 может быть связано с использованием пользователями блокировщиков рекламы (AdBlock). В тестовом периоде (20-22 октября) цифры совпали (5 заявок = 5 событий).
