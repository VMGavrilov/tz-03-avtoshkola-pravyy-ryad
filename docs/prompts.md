# Журнал запросов к нейросети

**Инструмент:** ChatGPT / Gemini (версия 4o / 1.5 Pro)

### Запрос 1. Общая структура и стили
**Текст:** «Ты — профессиональный веб-разработчик. Напиши CSS-файл для сайта автошколы. Используй цвета #1F6FD1, #F5C518, #1E2329. Шрифты Montserrat и Inter. Адаптив 375/768/1280. Кнопки от 44px.»
**Что получилось:** CSS с переменными, современной сеткой и медиазапросами.
**Исправил вручную:** Поправил отступы в меню и цвета кнопок для точного соответствия фирменному стилю.

### Запрос 2. Главная страница (index.html)
**Текст:** «Напиши HTML для index.html. Подключи css/style.css. Блоки: Шапка, Первый экран (кнопка cta_click), Категории, Как проходит обучение, Тренажер ПДД, Отзывы, Подвал.»
